[size=5][b]▐ Overview — نبذة[/b][/size]

A complete [b]Modern Standard Arabic[/b] localization for [b]Fatal Claw[/b]. All 3,559 lines in the game — every dialogue, cinematic, journal entry, item, skill, region name, and menu — are translated directly from the [b]original Korean script[/b] (not relayed through English), and rendered in properly shaped, right-to-left Arabic with a dedicated Arabic font.

Arabic is added to the game as a genuine [b]11th language[/b]: it appears alongside the existing ten in the in-game language menu, and none of the other languages are touched or replaced.

تعريبٌ كاملٌ باللغة [b]العربية الفصحى الحديثة[/b] للعبة [b]Fatal Claw[/b]. جميع نصوص اللعبة — 3,559 سطرًا — من حواراتٍ ومشاهد سينمائية ومذكّرات وأصنافٍ ومهاراتٍ وأسماء مناطق وقوائم، مترجمةٌ مباشرةً عن [b]النصّ الكوريّ الأصليّ[/b] (وليست نقلًا عن الإنجليزية)، وتُعرَض بحروفٍ عربيةٍ متّصلةٍ سليمة من اليمين إلى اليسار بخطٍّ عربيٍّ مخصّص.

أُضيفت العربية إلى اللعبة بوصفها [b]لغةً حادية عشرة[/b] حقيقية: تظهر في قائمة اللغات إلى جانب اللغات العشر الأصلية، دون استبدال أيٍّ منها أو المساس بها.

[size=5][b]▐ Installation — التثبيت[/b][/size]

[b]Option A — Installer (recommended):[/b]
[list=1]
[*]Download [b]Fatal Claw Arabic Installer.exe[/b] from the Files tab.
[*]Close the game completely, then run the installer. It auto-detects your Steam copy (or lets you pick the folder manually).
[*]Click [b]تثبيت اللغة العربية[/b] (Install). It copies one add-on file — done in a second.
[*]Launch the game → [b]Options → Language → العربية[/b].
[/list]
[b]To uninstall:[/b] run the installer again and click [b]إزالة اللغة العربية[/b] (Uninstall). It removes only the file it added.

[b]Option B — Manual:[/b]
[list=1]
[*]Download [b]FatalClaw_Arabic_v1.0_Manual.zip[/b] and extract [b]FatalClawArabic_P.pak[/b].
[*]Copy it into [b]…\Steam\steamapps\common\Fatal Claw\FatalClaw\Content\Paks\[/b] (next to [i]FatalClaw-WindowsNoEditor.pak[/i]).
[*]Launch the game → [b]Options → Language → العربية[/b].
[/list]
[b]To uninstall:[/b] delete [b]FatalClawArabic_P.pak[/b] from the Paks folder.

[b]الطريقة الأولى — المُثبِّت (موصى بها):[/b]
[list=1]
[*]حمِّل [b]Fatal Claw Arabic Installer.exe[/b] من قسم الملفات.
[*]أغلق اللعبة تمامًا ثم شغِّل المُثبِّت. سيكتشف موقع اللعبة تلقائيًّا (أو حدِّد المجلد يدويًّا).
[*]اضغط [b]تثبيت اللغة العربية[/b]. يُنسَخ ملفٌّ إضافيٌّ واحد — ينتهي خلال ثانية.
[*]شغِّل اللعبة ← [b]الإعدادات ← اللغة ← العربية[/b].
[/list]
[b]للإزالة:[/b] شغِّل المُثبِّت مرّة أخرى واضغط [b]إزالة اللغة العربية[/b]؛ يُحذَف الملف الذي أضافه فقط.

[b]الطريقة الثانية — يدويًّا:[/b]
[list=1]
[*]حمِّل [b]FatalClaw_Arabic_v1.0_Manual.zip[/b] واستخرج [b]FatalClawArabic_P.pak[/b].
[*]انسخه إلى [b]…\Steam\steamapps\common\Fatal Claw\FatalClaw\Content\Paks\[/b] (بجانب [i]FatalClaw-WindowsNoEditor.pak[/i]).
[*]شغِّل اللعبة ← [b]الإعدادات ← اللغة ← العربية[/b].
[/list]
[b]للإزالة:[/b] احذف [b]FatalClawArabic_P.pak[/b] من مجلد Paks.
